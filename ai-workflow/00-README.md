# AI Workflow

My reusable rules for building any project with an AI assistant. The goal is quality code: readable, clear, maintainable, and secure.

## How to use

1. Read every file in this folder, in order, before starting any work.
2. Read the project's own `[inventory-management-system-docs]`
3. If a project rule conflicts with a rule here, the project rule wins, except for security rules, which are never relaxed.

## Files

| File                       | Purpose                                    |
| -------------------------- | ------------------------------------------ |
| `01-introduction.md`       | What I want from my code and why           |
| `02-process.md`            | How we work together, step by step         |
| `03-code-standards.md`     | Rules for readable, maintainable code      |
| `04-security.md`           | Rules for protecting data and access       |
